# 예약 확정 안내와 같은 시간 예약 마감

예약확정 안내를 승인하면 기존 메시지 발송과 별개로 `booking_slot_closures`에 마감 작업을 저장한다. 추가 질문만 승인하면 마감 작업을 만들지 않는다. 저장된 talkId로 API 발송하는 고객도 마감은 로그인된 PC의 Edge 확장을 사용한다.

범위는 모든 상품의 **동일 날짜·동일 시작 시간**이다. 해당 시간 회차가 없는 상품은 건너뛴다. 다른 시간, 전체 날짜 마감, 상품 노출 여부는 변경하지 않는다. 이미 꺼진 스위치는 다시 누르지 않는다. 현재 간단예약관리에서 확인된 정시 회차만 지원하며 분 단위 회차나 모호한 화면은 실패로 표시한다.

확장은 비활성 탭에서 날짜를 선택하고 해당 시간 스위치를 끈다. 새로고침한 화면에서 다시 같은 날짜를 선택해 모든 대상 스위치가 꺼졌는지 확인한 후 완료를 기록한다. 메시지 발송 상태와 마감 상태를 별도로 표시한다. 마감만 실패한 경우 ‘시간 마감만 재시도’는 고객 메시지를 재발송하지 않는다.

마감 작업은 동시 실행을 방지하며 일시 오류는 최대 3회 처리한다. 중단된 마감 작업은 10분 뒤 상태를 다시 확인할 수 있다. 네이버 로그인 실패 시 기존 재로그인 알림을 사용하며 확장을 중지한다. 사용자가 로그인 후 자동 처리를 재개해야 한다. 취소·시간 변경된 예약의 오래된 마감 작업은 실행하지 않는다. 취소 후 회차를 자동으로 다시 열지는 않는다.

운영 적용 순서:

1. `0029_booking_slot_closures.sql` 적용 및 Worker 배포.
2. 기존 확장 폴더에 `background.mjs`, `slot-actions.mjs` 반영 후 Edge 확장 새로고침. 추가 권한 없음.
3. PC 실행기의 watcher와 `lib/slot-closure-worker.mjs` 반영 후 작업이 없는 때 재시작.

테스트: `test/booking-confirmation.spec.ts`, `test/slot-actions.node.mjs`. 실제 테스트는 지정된 확정 예약의 마감 작업만 실행하고 고객 메시지는 보내지 않는다.
