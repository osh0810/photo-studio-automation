# 일반 Edge 예약 발송 연결

로그인된 Edge의 예약·톡톡 화면을 확장 프로그램이 처리합니다. OS 마우스·키보드 입력을 사용하지 않습니다. 보안 확인이 발생하지 않는다고 보장하지는 않습니다.

## 설치

1. 평소 네이버에 로그인하는 Edge에서 `edge://extensions`를 엽니다.
2. 개발자 모드를 켠 뒤 **압축 풀린 확장 로드**에서 이 폴더를 선택합니다.
3. 기존 예약실행기-시작.cmd 또는 Windows 자동 시작으로 PC 실행기를 시작합니다.
4. `http://127.0.0.1:18766/`에 표시된 연결 코드를 확장 프로그램 팝업에 입력합니다. 처음 연결은 10분 이내에 진행합니다.
5. 자동 처리는 꺼둔 채 실행기 페이지의 **김윤영님 연결만 시험**으로 예약번호·이름·톡톡 연결을 검증합니다. 진단은 메시지를 보내지 않습니다.
6. 검증 후 확장 프로그램에서 **승인 건 자동 처리 켜기**를 누릅니다. 비서에서 승인된 메시지만 처리합니다.

PC 실행기는 관리자 API 키를 기존 로컬 설정에서 읽습니다. 확장은 localhost 전용 연결 토큰만 저장합니다. 연결 정보와 자동 처리 설정은 PC 실행기 재시작 후에도 유지됩니다.

## 운영

- talkId가 있는 고객은 기존 서버 API로 발송합니다.
- 최초 고객은 전용 비활성 탭에서 예약번호와 전체 이름을 읽고, 그 예약의 톡톡 주소를 확인합니다. 팝업을 새 전경 창으로 띄우지 않습니다.
- 이름으로 talkId를 추측하지 않습니다. 기존 예약확정 echo 매칭으로 talkId를 저장합니다. 추가 질문을 먼저 보낸 경우에는 예약확정 echo가 들어온 뒤 연결됩니다.
- 메시지를 화면에서 보낸 뒤 실제 발신 말풍선을 확인합니다. 확인 실패·연결 끊김은 재발송하지 않고 결과 확인 상태로 남습니다.
- 로그인·보안 확인은 직접 완료해야 합니다. 발생하면 승인 건을 대기시키고 자동 처리를 중지합니다. 일반 Edge에서 로그인 후 확장 팝업에서 다시 켭니다.
- PC와 Edge가 켜져 있어야 합니다. Windows 로그인 시 PC 실행기는 자동 시작되지만 Edge까지 자동으로 열지는 않습니다.
- Windows 잠금이나 절전 상태에서의 실제 동작은 아직 검증하지 않았습니다. 실행기는 기존 절전 방지 요청을 유지합니다.
- 작업 탭은 결과 확인을 위해 남겨둡니다. 평소 작업하던 탭을 사용하거나 닫지 않습니다.

## 접근 범위

확장은 `partner.booking.naver.com`, `partner.talk.naver.com`, `127.0.0.1`에서만 접근 권한을 요청합니다. 네이버 로그인 페이지, 비밀번호, 쿠키 읽기 권한은 요청하지 않습니다. 확장 설치와 접근 권한 승인은 사용자가 직접 확인해야 합니다.

## 검증 범위

자동화 테스트는 브리지 인증·원본 확인·타임아웃·명령 재발행 차단·예약 검증·캡차 정지와 기존 발송 조합을 확인합니다. 실제 Edge 설치 후 네이버 페이지에서 진단과 발송 검증을 완료하기 전에는 운영 검증 완료로 간주하지 않습니다.
